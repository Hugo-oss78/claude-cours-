Module 8 · Code & build

Claude Code

Claude Code est un agent spécialisé qui travaille directement sur de vrais projets logiciels : il lit vos fichiers, écrit du code, l'exécute, corrige ses propres erreurs, et peut construire une application complète de bout en bout. C'est l'outil qui a servi à construire ce cours que vous lisez actuellement.

Transparence Je suis Claude Code, exécuté ici sous forme d'agent en ligne de commande. Je ne connais pas avec certitude tous les détails actuels de disponibilité (interface web, application, extensions d'éditeur) au moment où vous lisez ceci — ces produits évoluent vite. Ce qui suit décrit le fonctionnement général, vérifiez les modalités d'accès précises sur claude.com.

Ce que Claude Code sait faire

🧱 Générer du code

Construire une page web, une fonction, une application complète à partir d'une description.

📖 Expliquer du code

Comprendre et vous expliquer un projet existant, même si vous ne savez pas coder.

🐛 Déboguer

Trouver et corriger l'origine d'un bug en lisant le code et les messages d'erreur.

🔧 Refactoriser

Réorganiser du code existant pour le rendre plus simple à maintenir, sans changer son comportement.

📚 Documenter

Écrire des explications claires sur le fonctionnement d'un projet pour vous ou pour un futur développeur.

📊 Analyser des données

Traiter des fichiers (tableurs, exports de réservations) pour en sortir des statistiques.

Comment ça se passe concrètement, sans jargon

  • Vous décrivez ce que vous voulez construire

    En langage naturel, comme dans une conversation normale : "je veux un site avec une page d'accueil, une page de réservation, et un formulaire de contact."

  • Claude Code planifie et écrit le code

    Il crée les fichiers nécessaires (pages, styles, logique) directement dans votre projet.

  • Il teste et corrige

    Il peut exécuter le code, voir s'il fonctionne, et corriger lui-même les erreurs qu'il détecte.

  • Vous validez ou demandez des ajustements

    Vous restez décisionnaire : vous demandez des changements comme pour un Artifact, mais sur un vrai projet complet et persistant.

  • Vous mettez en ligne (déploiement)

    Une fois satisfait, le projet est publié sur un hébergement pour devenir accessible à vos voyageurs (voir module 9).

    • Pourquoi ce module compte pour Love Room

    Les modules précédents (Artifacts, Skills, Workflows, Automation) fonctionnent très bien pour de l'aide ponctuelle. Mais pour avoir un vrai site de réservation en ligne, accessible à tous vos voyageurs, avec des automatisations qui tournent sans vous, il faut un vrai projet logiciel — c'est le rôle de Claude Code.

    Ce à quoi ressemble une demande à Claude Code "Construis un site de réservation pour mon appartement Love Room : page d'accueil avec présentation et galerie photo, page calendrier de disponibilité, formulaire de demande de réservation qui envoie un email de notification, et une page 'infos pratiques' pour les voyageurs déjà réservés. Utilise un design simple, moderne, couleurs terracotta et beige, adapté mobile."

    Ce qu'il faut savoir avant de se lancer

    • Vous n'avez pas besoin de savoir coder pour commencer — décrivez votre besoin en langage courant, Claude Code s'occupe du code.
    • Il est utile (mais pas obligatoire) de comprendre les bases : qu'est-ce qu'un site web, un hébergement, un nom de domaine — voir le glossaire dans les ressources.
    • Pour un projet destiné à de vrais clients qui paient, prévoyez une relecture humaine (vous, ou une personne de confiance) avant chaque mise en ligne importante.
    • Gardez toujours une sauvegarde de votre projet (via un système de gestion de version comme Git/GitHub) — Claude Code sait s'en servir et vous pouvez le lui demander explicitement.
