Module 5 · Workflow design

Les Workflows

Un workflow, c'est simplement un enchaînement d'étapes que vous répétez pour produire un résultat fiable — au lieu d'improviser à chaque fois. C'est ce qui transforme "je discute avec Claude" en "j'ai un vrai processus métier".

Le schéma de base

IDÉE → RECHERCHE → CRÉATION → RELECTURE → RAFFINAGE
  • Idée — le déclencheur : une nouvelle réservation, une question client, une fin de mois.
  • Recherche — rassembler l'information nécessaire (dates, historique du client, données du mois).
  • Création — Claude produit le contenu ou l'analyse demandée.
  • Relecture — vous (ou Claude lui-même) vérifiez la qualité, la justesse, le ton.
  • Raffinage — ajustements avant validation finale.

Pourquoi documenter un workflow

✅ Qualité constante

Le même niveau de qualité, réservation après réservation, sans dépendre de votre mémoire du jour.

♻️ Réutilisable

Vous (ou une personne qui vous aide) pouvez suivre le même processus sans tout réinventer.

🔍 Contrôle qualité intégré

Une étape de relecture systématique évite les erreurs qui abîment votre image (faute dans un message, mauvaise date...).

🤖 Base de l'automatisation

Un workflow clair et répété à la main est la première étape avant de l'automatiser complètement (module 7).

Exemple : le workflow "nouvelle réservation" pour Love Room

  • Idée / déclencheur

    Une nouvelle réservation arrive sur votre plateforme de location (Airbnb, Booking, ou votre propre site).

  • Recherche

    Claude rassemble : dates du séjour, nombre de voyageurs, éventuel historique (client déjà venu ?).

  • Création

    Génération du message de confirmation personnalisé + ajout au calendrier + mise à jour du tableau de suivi.

  • Relecture

    Vérification : bonnes dates, bon prénom, ton correct, aucune information sensible erronée.

  • Raffinage

    Envoi. Le workflow se répète automatiquement le jour J-1 (rappel), le jour J (accueil), et J+1 après départ (remerciement + demande d'avis) — voir module 7 pour automatiser cet enchaînement.

    • À essayer maintenant "Aide-moi à écrire, étape par étape, le workflow complet que je dois suivre à chaque nouvelle réservation pour mon appartement Love Room, de la confirmation de réservation jusqu'à la demande d'avis après le départ. Présente-le sous forme de liste numérotée avec, pour chaque étape, ce qu'il faut faire, quand, et le message ou l'action associée."
