Module 9 · Du débutant au power user

Projets pratiques : site, application, agent

Ce module rassemble tout ce qui précède dans trois parcours guidés. Suivez-les dans l'ordre : chaque projet réutilise ce que vous avez appris dans les modules 1 à 8.

Quel Claude ?Claude.ai pour cadrer/prototyper (premières étapes) → Claude Code pour construire (étapes suivantes).
Plateforme📱 💻 mobile/web ok pour cadrer et prototyper · 🖥️ ordinateur nécessaire dès la construction.

Projet A — Construire un site vitrine

Objectif : un site simple qui présente votre activité, sans logique complexe derrière (pas encore de réservation automatique).

  • Cadrez le besoin (module 2)

    Écrivez en une phrase l'objectif du site, le public visé, et les 3-5 pages indispensables.

  • Prototypez avec un Artifact (module 3)

    Demandez une première version visuelle rapide, pour valider le style et le contenu avant d'investir du temps.

  • Construisez le vrai projet avec Claude Code (module 8)

    Une fois le prototype validé, demandez la version complète, avec plusieurs pages reliées entre elles.

  • Testez

    Ouvrez le site sur ordinateur et sur mobile. Vérifiez que rien ne casse sur petit écran.

  • Publiez

    Demandez à Claude Code de vous accompagner pour la mise en ligne (hébergement + nom de domaine). Voir le glossaire pour ces deux termes.

    • Projet B — Construire une petite application

    Objectif : un outil qui fait plus qu'afficher de l'information — il garde un état, réagit à une action (ex : un formulaire de réservation qui enregistre une demande).

  • Listez les actions possibles

    Que doit pouvoir faire un visiteur ? (ex : consulter les dates dispo, envoyer une demande, recevoir une confirmation)

  • Définissez où vivent les données

    Où seront stockées les réservations ? Un tableau, une base de données simple ? Demandez conseil à Claude Code selon votre niveau technique.

  • Construisez petit à petit

    Une fonctionnalité à la fois : d'abord l'affichage, puis le formulaire, puis la notification par email. Ne demandez pas "tout" en un seul prompt géant.

  • Testez chaque étape avant de passer à la suivante

    Un bug détecté tôt est bien plus simple à corriger qu'un bug découvert à la fin.

  • Documentez pour vous-même

    Demandez à Claude Code un mode d'emploi simple : comment ajouter une info, changer un prix, etc. — utile si vous n'y touchez pas pendant plusieurs mois.

    • Projet C — Construire un agent

    Objectif : un "agent" qui exécute lui-même une suite d'actions pour atteindre un but, avec moins d'intervention manuelle qu'une simple conversation (ex : surveiller les prix concurrents chaque semaine et produire un rapport).

  • Définissez le but, pas seulement la tâche

    Un agent réussit ou échoue par rapport à un objectif clair : "réduire le temps de réponse aux voyageurs à moins de 15 minutes", pas juste "répondre aux messages".

  • Donnez-lui des outils précis (module 6)

    Un agent n'est utile que s'il peut réellement accéder à l'information (agenda, boîte mail) et agir (envoyer un message) via des connecteurs autorisés.

  • Posez des limites claires (module 7)

    Quelles actions l'agent peut faire seul, lesquelles nécessitent votre validation. Commencez restrictif, élargissez avec la confiance.

  • Faites-le tourner en surveillance avant de le laisser seul

    Observez plusieurs cycles complets avant de lui faire confiance sans relecture.

  • Prévoyez un moyen de tout arrêter

    Sachez toujours comment couper une automatisation qui se comporterait mal (ex : messages envoyés en boucle).

    • Honnêteté sur le niveau de difficulté Le Projet A (site vitrine) est accessible à un débutant complet en une à quelques sessions de travail. Le Projet C (agent autonome connecté à vos outils réels) demande plus de rigueur technique et de tests — ne sautez pas les étapes de test, même si Claude Code peut aller vite. Je ne peux pas vous garantir un temps de réalisation précis : cela dépend énormément de la complexité que vous visez.

    Récapitulatif : de débutant à power user

    ÉtapeCe que vous savez faire à la fin
    Débutant (modules 1-2)Discuter efficacement avec Claude, obtenir de bonnes réponses du premier coup.
    Intermédiaire (modules 3-5)Produire des contenus réutilisables (Artifacts, Skills) et des processus documentés (Workflows).
    Avancé (modules 6-7)Connecter Claude à vos vrais outils et automatiser des tâches répétitives avec des garde-fous.
    Power user (modules 8-10)Construire un vrai produit logiciel (site, appli, agent) et l'appliquer à un objectif business réel.
