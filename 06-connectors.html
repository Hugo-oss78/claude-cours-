Module 6 · Connect & integrate

Les Connectors

Par défaut, Claude ne voit que ce que vous lui copiez dans la conversation. Les "connectors" (connecteurs) sont des ponts autorisés vers vos outils réels — boîte mail, agenda, stockage de fichiers, tableurs, dépôts de code — pour que Claude travaille directement avec vos vraies données, sans copier-coller manuel.

Comment ça fonctionne, simplement

  • Vous autorisez la connexion

    Vous donnez accès à un compte (ex : votre Gmail) via une procédure d'autorisation sécurisée — Claude ne récupère pas votre mot de passe.

  • Claude peut lire (et parfois agir)

    Selon le connecteur, Claude peut consulter des informations (lire un email, un fichier) et parfois agir (envoyer un brouillon, créer un événement).

  • Vous gardez le contrôle

    Vous pouvez révoquer l'accès à tout moment, et certaines actions sensibles demandent une confirmation explicite.

    • Connecteurs utiles pour Love Room

    Connecteur (type)Usage pour Love Room
    Boîte mail (ex : Gmail)Lire les nouvelles réservations, préparer des réponses, trier les demandes clients.
    Agenda (ex : Google Calendar)Voir les arrivées/départs, planifier le ménage et la maintenance sans conflit.
    Stockage de fichiers (ex : Google Drive)Accéder au tableau de suivi des réservations, aux factures, aux contrats de ménage.
    Espace de travail / notes (ex : Notion)Centraliser les procédures, les fiches fournisseurs (femme de ménage, artisans), le suivi des travaux.
    Dépôt de code (ex : GitHub)Si vous développez votre propre site (module 8-9), Claude Code peut lire/modifier directement le code source.
    Point à vérifier La liste exacte des connecteurs disponibles, leur nom commercial, et les niveaux d'accès (lecture seule ou lecture/écriture) dépendent de votre plan et évoluent avec les mises à jour du produit. Je ne peux pas garantir que tous les connecteurs cités ci-dessus sont disponibles sur votre compte au moment où vous lisez ceci — vérifiez la liste actuelle directement dans les paramètres de votre compte Claude.

    Exemple d'usage concret

    Une fois un connecteur agenda actif "Regarde mon agenda Love Room pour les 7 prochains jours. Liste les arrivées et départs, et prépare pour chacun un message adapté au bon moment (bienvenue, rappel check-out, remerciement)."

    Sécurité et bon sens

    • Ne connectez que des comptes dont vous comprenez l'usage prévu — commencez par un seul connecteur (ex : l'agenda) avant d'en ajouter d'autres.
    • Vérifiez régulièrement, dans les paramètres de votre compte, la liste des connexions actives et retirez celles que vous n'utilisez plus.
    • Pour des données très sensibles (comptabilité, informations bancaires), privilégiez toujours une vérification humaine avant toute action automatique — voir les garde-fous proposés au module 7.
